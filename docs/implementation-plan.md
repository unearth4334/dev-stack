# Implementation plan

The active delivery plan is [Pilot v0.1: concurrent agent workspaces](pilot/index.html), published at [the GitHub Pages plan URL](https://unearth4334.github.io/dev-stack/pilot/).

It defines the seven dependency-ordered phases, architecture, acceptance matrix, review process and rollback strategy for running Codex CLI and Claude Code on dev-host through private QNAP control, starting with two workers and validating five.

The [original platform roadmap](platform-roadmap.md) is preserved as background for later features. Its phase numbering is historical; use the pilot page and milestone for current work. Hardware and remaining access questions are in the [inventory](inventory.md); product evidence is in the [research report](research.md).

No phase is complete until its issue's acceptance criteria pass, relevant checks and reviews are addressed, its PR is merged, and required deployed behavior is verified.
